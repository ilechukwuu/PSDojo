# Aufgabe

Drei Zeilen aus der Dienstüberwachung von APP-01 liefern das falsche Ergebnis. Jede hat einen
Fehler innerhalb der Klammern. Behebe die Bedingungen und ändere sonst nichts.

- `$Stopped` muss die gestoppten Dienste enthalten.
- `$Nordwind` muss die Dienste enthalten, deren Name mit Nordwind beginnt.
- `$Running` muss die laufenden Dienste enthalten.
