# Module 8 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `Where-Object { $_.Property -eq 'value' }` filters the pipeline.
- Comparison operators start with a hyphen: `-eq`, `-ne`, `-gt`, `-lt`.
- The left side decides between text and number comparison.
- Wildcards need `-like`.
- `-and`, `-or`, `-in` combine conditions.
- Filter left: let the first command filter where it can.
