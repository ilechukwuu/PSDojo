# Module 15 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `AddDays`, `AddMonths` and `AddHours` return a new date.
- Date minus date is a TimeSpan.
- `Days` is a share, `TotalDays` the whole duration.
- Write dates with `ToString('yyyy-MM-dd')`.
- Read foreign layouts with `ParseExact`.
- Compare dates as dates, never as text.
