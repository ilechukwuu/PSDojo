# Module 20 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `-match` tests a text against a pattern and fills `$Matches`.
- `\d` digit, `\w` word character, `\s` white space, `+` one or more.
- A dot is any character, `\.` a real dot.
- `^` and `$` anchor the pattern to the whole text.
- `-replace` uses `$1` in single quotes for captured parts.
- `Select-String` searches files and returns matches as objects.
