# Aufgabe

Das Skript in deiner Übungsdatei findet die drei größten Prozesse auf TS-03 und zählt sie. Es
funktioniert, schleppt aber vier Wegwerfvariablen mit.

Schreibe es um:

1. `$Report` wird durch eine einzige Pipeline zugewiesen, die mit `Get-Process` beginnt.
2. `$ReportCount` wird aus `$Report` berechnet.
3. Keine andere Variable wird zugewiesen. `$a`, `$b`, `$c` und `$d` verschwinden.

`$Report` und `$ReportCount` müssen genau das enthalten, was sie jetzt enthalten.
