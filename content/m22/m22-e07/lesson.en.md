# Module 22 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `Join-Path` builds paths, `Split-Path` takes them apart.
- `Test-Path` answers whether a path exists, `-PathType` asks for file or folder.
- `Get-ChildItem -Recurse -File -Filter` searches folder trees.
- `Length` is the size in bytes, `LastWriteTime` the date of the last change.
- `Copy-Item` needs `-Recurse` for folder content.
- `Remove-Item` is final. Collect first, try with `-WhatIf`, then delete.
