# Task

Your exercise file becomes a small check script for APP-01. Other scripts will capture its
result, and people will run it by hand.

1. Write the heading `Nordwind service check for APP-01` for the person at the screen.
2. Return the names of the services whose name starts with `Nordwind` as the result of the
   script, as plain text, one name per service.
3. Write the closing line `Check finished` for the person at the screen.

The result of the script must consist of the three names and nothing else.
