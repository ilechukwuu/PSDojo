# Module 9 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `Sort-Object` sorts by one or several properties.
- `Select-Object -Property` builds narrow objects, `-ExpandProperty` returns values.
- `Group-Object` returns groups with `Name`, `Count` and `Group`.
- `Measure-Object` calculates sum, average, maximum and minimum.
- Calculated properties need a script block in `Expression`.
- Select at the end, when the full object is no longer needed.
