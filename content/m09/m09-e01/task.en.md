# Task

The weekly service report for APP-01 needs the data in three shapes.

1. Store all services sorted by `Status` and, within the same status, by `Name` in
   `$Sorted`.
2. Store objects that have only the properties `Name` and `StartType` in `$Narrow`. One
   object per service.
3. Store every `StartType` that occurs exactly once, as plain text and sorted, in
   `$StartTypes`.
