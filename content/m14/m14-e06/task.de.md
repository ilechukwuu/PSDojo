# Aufgabe

Die zwei Zeilen in deiner Übungsdatei bauen Texte für den wöchentlichen Datenträgerbericht
mit langen Ketten von `+`. Schreibe sie um.

1. `$Line` wird ein Text in doppelten Anführungszeichen mit eingesetzten Werten.
2. `$Path` wird ebenfalls ein Text. Achte auf die Eigenschaft von `$Disk`.

Kein `+` darf in der Datei übrig bleiben. `$Line` und `$Path` müssen genau dieselben Texte
enthalten wie jetzt. Lass die ersten drei Zeilen unverändert.
