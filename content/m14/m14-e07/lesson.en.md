# Module 14 in review

This quiz closes the module. It covers what you have used in the exercises before:

- Single quotes are literal, double quotes replace variables.
- A property or a calculation inside a text needs `$( )`.
- `${Name}` marks where a variable name ends.
- `-f` fills numbered placeholders and formats values.
- A here-string holds text over several lines.
- `Trim`, `Split`, `ToUpper` and `EndsWith` clean up and test text.

You pass with 80 percent. If you fail you can try again as often as you like. The feedback
tells you which questions were wrong, not what the right answer is.
