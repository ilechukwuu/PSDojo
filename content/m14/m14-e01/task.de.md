# Aufgabe

Du baust die Texte für eine Warnmail zu einem Datenträger. Die ersten Zeilen deiner
Übungsdatei enthalten die Daten. Lass sie unverändert.

1. Speichere den Text `Disk warning for FS-02` in `$Subject`. Setze den Wert von `$Server`
   ein.
2. Speichere den Text `Drive D: has 75 GB free` in `$Line`. Setze die Eigenschaften `Letter`
   und `FreeGB` von `$Disk` ein.
3. Speichere den Text `FS-02_2026.log` in `$LogName`. Setze `$Server` und `$Year` ein.
4. Speichere den wörtlichen Text `Set $Limit in config.psd1` in `$Hint`. Darin darf nichts
   ersetzt werden.
