# Task

A colleague wrote a morning check for terminal server TS-03 and then left for a holiday. The
script in your exercise file contains three mistakes, one per line.

Fix the mistakes. Do not rewrite the script, change only what is broken. Run the file after
each change and read the next error message.

When the script works:

- `$Spooler` holds the process named spoolsv.
- `$ProcessCommands` holds every command with the noun Process.
- `$Stamp` holds today's date as text, for example 2026-03-14.
