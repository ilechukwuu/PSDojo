# Module 1 in review

This quiz closes the module. It covers what you have used in the last seven exercises:

- Cmdlets return objects, not text.
- Names follow Verb-Noun, and the verb tells you whether a command only reads.
- `Get-Command` finds commands by verb, noun or name.
- Error messages name the word PowerShell did not understand.
- Parameters are named, positional or switches.
- Aliases belong in the console, full names belong in scripts.

You pass with 80 percent. If you fail you can try again as often as you like. The feedback
tells you which questions were wrong, not what the right answer is.
