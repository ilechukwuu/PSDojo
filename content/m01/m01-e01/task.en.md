# Task

You start the early shift on the service desk. Before the first ticket comes in you check
print server PRN-01. Open your exercise file and complete the three lines.

1. Store the current date and time in `$CheckTime`.
2. Store all running processes in `$Processes`.
3. Store the folder you are currently in in `$Location`.

Use one cmdlet per line: `Get-Date`, `Get-Process` and `Get-Location`.
