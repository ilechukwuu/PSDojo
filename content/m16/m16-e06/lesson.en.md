# Module 16 in review

This quiz closes the module. It covers what you have used in the exercises before:

- An array is a list with positions from 0.
- `[-1]` is the last element, `[1..2]` a slice.
- One result is not an array. `@( )` makes it one.
- Arrays have a fixed size, `+=` builds a new one.
- A generic List grows with `Add` and shrinks with `Remove`.
- Good list code works for any length.
