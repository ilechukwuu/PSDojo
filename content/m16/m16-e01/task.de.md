# Aufgabe

Der Patchplan listet die Dateiserver in der Reihenfolge, in der sie gepatcht werden. Du
brauchst ein paar Fakten aus dieser Liste.

1. Speichere die fünf Servernamen `FS-01`, `FS-02`, `FS-03`, `FS-04` und `FS-05` als Array in
   `$Servers`, in dieser Reihenfolge.
2. Speichere den ersten Server in `$Pilot`. Er wird zuerst gepatcht.
3. Speichere den letzten Server in `$Final`. Nutze einen negativen Index.
4. Speichere den zweiten und dritten Server als Array in `$WaveTwo`. Nutze einen Bereich.
5. Speichere die Anzahl der Server in `$Total`.
