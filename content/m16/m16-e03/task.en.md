# Task

During a patch night servers join and leave the work queue. You manage it in your exercise
file.

1. `$Done` is an array with `FS-01`. Append `FS-02` to it with `+=`.
2. Create a generic List of strings in `$Queue`.
3. Add `FS-03`, `FS-04` and `FS-05` to `$Queue`, in this order.
4. `FS-04` is taken out of the plan. Remove it from `$Queue`.
5. Store in `$StillQueued` whether `$Queue` contains `FS-05`.
6. Store the number of servers left in `$Queue` in `$Waiting`.
