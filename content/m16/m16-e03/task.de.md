# Aufgabe

In einer Patchnacht kommen Server in die Arbeitswarteschlange und verlassen sie wieder. Du
verwaltest sie in deiner Übungsdatei.

1. `$Done` ist ein Array mit `FS-01`. Hänge `FS-02` mit `+=` an.
2. Lege in `$Queue` eine generische List von Strings an.
3. Füge `FS-03`, `FS-04` und `FS-05` in dieser Reihenfolge zu `$Queue` hinzu.
4. `FS-04` wird aus dem Plan genommen. Entferne es aus `$Queue`.
5. Speichere in `$StillQueued`, ob `$Queue` `FS-05` enthält.
6. Speichere die Zahl der Server, die in `$Queue` übrig sind, in `$Waiting`.
