# Module 19 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `foreach ($x in $list)` runs once per element.
- `ForEach-Object` is the loop inside a pipeline, with `$_`.
- `for` counts, `while` checks first, `do` runs at least once.
- `break` ends the loop, `continue` skips one pass.
- A waiting loop needs a limit.
- Assign the result of a loop instead of using `+=`.
