# Task

The script in your exercise file builds the lines of a disk warning. It uses a counting
loop, an index and `+=`. Rewrite it.

1. Use a `foreach` statement over `$Disks`.
2. Assign the result of the loop to `$Warnings`. No `+=` may remain.
3. No `for` loop and no index such as `[$i]` may remain.

`$Warnings` must hold the same texts as now. Leave the first lines with the data as they
are.
