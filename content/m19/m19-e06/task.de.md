# Aufgabe

Das Skript in deiner Übungsdatei baut die Zeilen einer Datenträgerwarnung. Es benutzt eine
Zählschleife, einen Index und `+=`. Schreibe es um.

1. Nutze eine `foreach`-Anweisung über `$Disks`.
2. Weise das Ergebnis der Schleife `$Warnings` zu. Kein `+=` darf übrig bleiben.
3. Keine `for`-Schleife und kein Index wie `[$i]` darf übrig bleiben.

`$Warnings` muss dieselben Texte enthalten wie jetzt. Lass die ersten Zeilen mit den Daten
unverändert.
