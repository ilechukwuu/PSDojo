# Task

The disk monitoring warns at a different amount of free space for each drive. You keep
these limits in a hashtable.

1. Create a hashtable in `$Limits` with the key `C:` and the value 10 and the key `D:` and
   the value 50.
2. Add the key `E:` with the value 20.
3. The limit for `C:` rises. Change its value to 15.
4. Store the limit for `D:` in `$LimitD`.
5. Store in `$HasF` whether the key `F:` exists.
6. Store the number of drives in `$DriveCount`.
