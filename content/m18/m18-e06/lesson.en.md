# Module 18 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `if` runs a block only when its condition is true.
- Only the first matching block of an `if` chain runs.
- `$null`, 0, empty text and an empty array are false.
- `switch` checks one value against many cases.
- `default` catches the rest, `break` stops further matching.
- In a condition use `-eq`, never `=`.
