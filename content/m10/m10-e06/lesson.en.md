# Module 10 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `Format-Table`, `Format-List` and `Format-Wide` are three views of the same objects.
- `Format-List -Property *` shows everything an object contains.
- Format cmdlets return layout instructions, not data.
- Only `Out-` cmdlets may follow a format cmdlet.
- `Out-File` and `Out-String` need a generous `-Width`.
- Keep data in a variable and format only for display.
