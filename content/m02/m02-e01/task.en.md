# Task

Your exercise file contains three lines from a disk report for print server PRN-01. Open the
file in ISE or VS Code. Do not run the whole file.

Select each of the three lines on its own, press F8 and read the result in the console.

1. Store the number that the first line prints in `$FreePercent`.
2. Store the text that the second line prints in `$ServerName`.
3. Store the day that the third line prints as text in `$PatchDay`.
