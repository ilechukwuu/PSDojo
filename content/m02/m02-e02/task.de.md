# Aufgabe

Ein Kollege hat vier Zeilen aus einem Chat in eine Datei kopiert. Sie funktionieren, aber
nächsten Monat weiß niemand mehr, wozu sie da sind. Mach aus der Notiz ein Skript, das ein
Leser versteht. Ändere die vier Zeilen selbst nicht.

1. Beginne die Datei mit einem Blockkommentar, der die Wörter `Purpose` und `Author` enthält.
2. Setze die Zeilen für `$ServerName` und `$Contact` in eine Region namens `Settings`.
3. Setze die Zeilen für `$QueueCount` und `$ReportLine` in eine Region namens `Report`.
4. Schreibe einen einzeiligen Kommentar direkt über die Zeile mit `$QueueCount`.
