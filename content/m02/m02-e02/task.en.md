# Task

A colleague pasted four lines from a chat into a file. They work, but nobody will know next
month what they are for. Turn the note into a script that a reader understands. Do not
change the four lines themselves.

1. Start the file with a block comment that contains the words `Purpose` and `Author`.
2. Put the lines for `$ServerName` and `$Contact` into a region named `Settings`.
3. Put the lines for `$QueueCount` and `$ReportLine` into a region named `Report`.
4. Write a single-line comment directly above the line with `$QueueCount`.
