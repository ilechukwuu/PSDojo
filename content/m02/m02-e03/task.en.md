# Task

The three lines in your exercise file prepare a drive check for terminal server TS-03. Each
line contains one syntax error, so the file cannot run at all.

Open the file in your editor and use the squiggles and colors to find the three mistakes.
Fix them without rewriting the lines.

When the file is correct:

- `$ServerName` holds the text TS-03.
- `$Drives` holds the three drive letters.
- `$Summary` holds the text `Checked 3 drives on TS-03`.
