# Module 7 in review

This quiz closes the module. It covers what you have used in the exercises before:

- ByValue goes by type, ByPropertyName by the name of a property.
- ByValue is tried first.
- A list in front of the pipe travels element by element.
- Column names decide whether rows bind.
- Not every parameter takes pipeline input.
- A parameter of the type `string[]` takes a whole list in one call.
