# Task

A report script has to calculate with dates: how old is a file, when does a certificate
expire. Before you write it you find out what a date object offers.

1. Store everything `Get-Member` reports about the output of `Get-Date` in `$Members`.
2. Store only the properties in `$Properties`.
3. Store only the methods in `$Methods`.
4. Store the type name of the date object as text in `$TypeName`. You find it in the output
   of step 1.
