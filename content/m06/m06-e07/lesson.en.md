# Module 6 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `Get-Member` shows type, properties and methods.
- A property is read with a dot, and dots can be chained.
- Methods need parentheses and return a new value.
- Static members belong to the type: `[math]::Round()`.
- A property read on a list returns it from every element.
- The table on screen is only a picture of the object.
