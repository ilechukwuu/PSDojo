# Task

You write down the facts about a new file share as variables, so that a later script can
use them.

1. Store the text `FS-02` in `$Server`.
2. Store the whole number 445 in `$Port`.
3. Store the decimal number 81.5 in `$UsedPercent`.
4. Store the boolean value true in `$IsProduction`.
5. Store the current date and time in `$CheckedAt`.
6. Store the type name of `$UsedPercent` as text in `$PercentType`. Read it with
   `GetType().Name`, do not type it.
