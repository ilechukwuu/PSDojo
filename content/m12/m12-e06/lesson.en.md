# Module 12 in review

This quiz closes the module. It covers what you have used in the exercises before:

- A variable takes the type of its value.
- Text, whole number, decimal number, boolean and date behave differently.
- With mixed types the left side decides.
- Values from files are text until you cast them.
- A mistyped variable name is empty, not an error.
- Repeated values belong in one variable.

You pass with 80 percent. If you fail you can try again as often as you like. The feedback
tells you which questions were wrong, not what the right answer is.

