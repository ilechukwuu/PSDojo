# Aufgabe

Das Kapazitätsskript für FS-02 liefert falsche Werte. Es hat drei Fehler. Behebe sie, ohne
die ersten drei Zeilen zu ändern, die für Daten aus einer Datei stehen.

Wenn das Skript funktioniert:

- `$TotalGB` enthält die Zahl 120.
- `$DriveCount` enthält die Zahl 12.
- `$Line` enthält den Text `Server: FS-02`.
