# Task

A capacity script reads two values from a CSV file, so both arrive as text. A colleague
asks why its numbers are wrong. Predict what each line returns. Do not run anything.

```powershell
$Used = '81'
$Free = '39'

$Used + $Free
[int]$Used + $Free
$Used * 2
[int]2.5
[bool]'0'
```

1. Store what line 4 returns in `$Result1`, with the type it really has.
2. Store what line 5 returns in `$Result2`.
3. Store what line 6 returns in `$Result3`.
4. Store what line 7 returns in `$Result4`.
5. Store what line 8 returns in `$Result5`.
