# Module 25 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `function Verb-Noun { param(...) ... }` with an approved verb.
- The result is everything the function outputs. `Write-Host` returns nothing.
- Return objects with properties, not formatted text.
- `return` only ends the function. Discard unwanted values with `$null =`.
- Call with spaces and names, never with parentheses and commas.
- A function uses only its parameters.

You pass with 80 percent. If you fail you can try again as often as you like. The feedback
tells you which questions were wrong, not what the right answer is.

```powershell
$Answer1 = 'b'
```
