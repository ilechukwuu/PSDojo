# Task

The capacity report in your exercise file reads `disks.csv`, which is separated by
semicolons, and writes a summary as JSON. It has three mistakes. Fix them. Leave the line
with `param` as it is.

When the script works:

- `$Rows` holds rows with the properties `Server`, `Drive` and `FreeGB`.
- `$TotalFree` is the sum of all `FreeGB` values as a number.
- The file `summary.json` in `$Folder` still contains the drive letters of every row.
