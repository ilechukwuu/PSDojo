# Module 21 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `Import-Csv` returns one object per line, all values are text.
- `-Delimiter ';'` for files from a German Excel.
- `-NoTypeInformation` makes 5.1 and 7 write the same file.
- JSON nests and keeps numbers and booleans.
- `ConvertTo-Json` needs `-Depth`.
- `[xml]` reads XML, dots walk through elements and attributes.
