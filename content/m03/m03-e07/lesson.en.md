# Module 3 in review

This quiz closes the module. It covers what you have used in the exercises before:

- `Get-Help` shows help, examples and parameter details.
- Syntax diagrams say what is optional, positional, a switch or a list.
- `Get-Command` searches by parameter name and by module.
- Unknown parameter: look the name up, do not guess again.
- Scripts use full parameter names and no positional values.

You pass with 80 percent. If you fail you can try again as often as you like. The feedback
tells you which questions were wrong, not what the right answer is.

```powershell
$Answer1 = 'b'
```
