# Task

A process hangs on terminal server TS-03. A colleague tells you to use `Stop-Process` with
`-Force`. You have never used that cmdlet, so you read before you act.

1. Store the help for `Stop-Process` in `$Help`.
2. Store only the examples for `Stop-Process` in `$Examples`.
3. Store the help for its parameter `Force` in `$ForceHelp`.
4. Store the help for its parameter `Id` in `$IdHelp`.

Write the parameter name `-Name` out in every call.
