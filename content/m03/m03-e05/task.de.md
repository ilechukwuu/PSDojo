# Aufgabe

Die Zeilen in deiner Übungsdatei sammeln Logdateien für einen Bericht. Sie funktionieren,
benutzen aber positionale Werte und abgekürzte Parameternamen. Schreibe sie für ein Skript
um.

1. Gib jedem Wert seinen Parameternamen.
2. Schreibe jeden Parameternamen aus.

Lass die erste Zeile mit `param` unverändert. Das Dojo übergibt darüber einen Testordner.
Die Variablen müssen genau das enthalten, was sie jetzt enthalten.
